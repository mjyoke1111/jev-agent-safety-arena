The whole idea

Jev, explained like you’re five

Imagine there are 100 doors and a prize behind one of them.

A normal chatbot might write a little essay about every door, think out loud, and finally say, “I choose door 27.”

Jev does something smaller. You show it all the doors and ask a very specific question. It points to a door and tells you how strongly it leans that way.

No essay. No long conversation. Just the choice.

That makes Jev useful for jobs like sorting messages, choosing which tool should run next, scoring a piece of text, or deciding whether a human needs to look.

But it is still making a judgment, not discovering the truth. A neat answer box does not make the answer right.

Under the hood

One look. Many tiny answers.

You give Jev some context, then ask tightly shaped questions. It reads the shared context once and returns probability-like scores for the allowed answers. The technical point is simple: there is no word-by-word decode loop.

Four things to remember

Small box, sharp purpose

It chooses

Not a storyteller

Jev is for bounded decisions. If you want a poem, a plan, or a careful explanation, use a generative model.

It batches

Questions can run in parallel

Independent testing found that roughly 100 questions barely moved server time. In one test, 1,500 short questions took 610 ms versus 86.5 ms for one.

It is cheap

Because it skips generated prose

TypeSafe lists input at $0.042 per million tokens and output tokens as free. That is a vendor price, not a promise of total workflow cost.

It can be wrong

A score is not certainty

Jev’s Choice “confidence” measures distance above a uniform guess. It is not a calibrated probability that the answer is correct.

The catch

A confident pointer can still point at the wrong door.

Jev’s answer shape is controlled, but the judgment can still be pushed around by wording, option order, irrelevant choices, or hostile text in the context.

The strongest honest rule is: let Jev advise software, not quietly become the software’s final authority.

A sensible recipe

Give it a seat, not the steering wheel.

  1. Start in shadow mode.Let Jev make suggestions beside the existing system without taking action.
  2. Label real decisions.Measure mistakes on your own data, not someone else’s demo.
  3. Tune each question type.Noul, Choice and Score do not share interchangeable thresholds.
  4. Automate low-risk cases first.Send low-confidence or high-impact decisions to a human or stronger model.

The one-line version

Jev is a decision engine wearing an AI badge.

Give it a pile of context and a small set of allowed answers. It skips the essay, returns the lean, and lets ordinary code decide what happens next.
